Solecism: WYSIWYG and Social Writing Platform

- Fully local in the browser or as a web app. Need to figure out how to handle local files.
- Cloud sync option.
- Support for prose, poem, and screenplays.
- Minimal UI by default, advanced UI when needed.
- Works can be shared, and can be put behind a paywall.
- Account required to view published works, verified atleast by e-mail.
- Can follow artists, heart content, make comments, share.
- Leaderboards (daily, weekly, monthly, etc) for most liked, most read, etc.
- Awards will be given out, displayed on the artists profile.
- Homepage will display featured short poems / stories of the day.
