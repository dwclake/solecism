WYSIWYG and Social Writing Platform
- Fully local in the browser or as a web app.
- Cloud sync option.
- Support for prose, poem, and scripts.
- Minimal UI by default, advanced UI when needed.
- Works can be shared, and can be put behind a paywall.
- Can follow creators, like pieces, make comments.
- Leaderboards for most liked, most read, etc.
- Weekly and daily awards will be given out, displayed on the artists profile.
- Homepage will display featured short poems / stories of the day.
